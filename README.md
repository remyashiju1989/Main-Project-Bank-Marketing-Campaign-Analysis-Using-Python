# Main-Project-Bank-Marketing-Campaign-Analysis-Using-Python

## Project Overview
This project analyzes a bank marketing dataset using Python to understand customer behavior and identify factors influencing term deposit subscriptions.

## Tools Used
- Python
- Pandas and NumPy
- Matplotlib, Seaborn, and Plotly
- Google Colab

## Key Findings
- 11.51% of customers subscribed to a term deposit.
- Retired people and students showed higher subscription rates.
- Longer call durations were associated with higher subscription rates.
- Customers without housing loans had a higher subscription rate.

## Conclusion
This analysis provides useful business insights to help banks improve customer targeting and marketing campaign effectiveness.
